# Ariadna — вихідні файли

Готова сторінка — `../index.html` (її показує GitHub Pages). Її не правлять руками: її збирають звідси.

Збирання (з цієї папки):

    python3 restructure.py && python3 build.py && node /tmp/t.js

- `src_v31.html` — основа сторінки (розмітка, стилі, дані карти, малювання).
- `restructure.py` — правки поверх основи: нижня панель, віконця, двері, поверхи, сходи, обрив (дані — у блоці v5). Пише `src.html`.
- `tail.js` — логіка інтерфейсу (вибір, пошук, маршрут, геопозиція).
- `build.py` — підставляє `context.txt` (сусідні будівлі), `roofs.json` (дахи), `terrain.json` (рельєф) і пише `../index.html`; `node /tmp/t.js` — перевірка маршрутів.
- `terrain.py` + `dem.b64` — рельєф (висоти AWS Terrain Tiles, z15). `bld.json` — контури будівель з OpenStreetMap.
- `tools/sk` — розрахунок скатів дахів (npm `straight-skeleton`); `tools/shot.mjs` — знімки сторінки в headless Chrome.
- `tools/print.mjs` — аркуші для друку A4 (огляд, частини території, корпуси з відділеннями) в один PDF: `node tools/print.mjs ../index.html /tmp/print`.

Координати: метри на схід (x) і на південь (y) від 50.4820 N, 30.4695 E.

## v18 (19.11.2026) — «Звідки» без пам'яті, «Надіслати рідним»
- «Звідки» більше не запам'ятовується: щоразу старт — «Від мене» (`st.start="geo"`). Пам'ятається лише «Маршрут без сходів» (`localStorage.ariadna = {noSteps}`), «На авто» — ні. `?from=e1` у посиланні й далі працює.
- Геопозицію питаємо, коли людина обрала «Куди» (`geoAsk()`), або одразу, якщо посилання вже має `?to=`. Перші 30 с — точно (GPS), далі економно.
- Поки місце невідоме, точність гірша за 100 м або людина далі 650 м від лікарні — нитка від найзручнішої зупинки (`pickStop`: найкоротше територією; далеко — ще й найближча до людини). Геопозицію заборонили — зупинка обирається сама (`st.auto`), доки людина не обере іншу.
- Далеко: банер «Ви за ≈ N км» з кнопкою «Як дістатися» → Google Карти «Транспортом» до зупинки (`pickStop`) або «Автомобілем» до в'їзду (`pickGate`). Стеження вимикається; повернення на вкладку — перевіряємо місце ще раз.
- Людина вже біля дверей (< 25 м) або в цьому корпусі — «Ви вже тут» і кнопка «Надіслати». Посилання для рідних має лише `?to=…` (без «Звідки»).
- QR (`qr/ariadna-qr.*`) не змінювався: він веде на https://ariadna-map.github.io/ без параметрів — саме те, що треба.
- Синя точка на нитці (19.11.2026, після проходу від зупинки до 16 відділення, де GPS стрибав на 30–60 м): точки згладжуються (`geoFilter`), маршрут від вас «замикається» (`LOCK`), точка рухається тільки по нитці (`lockStep`), не швидше за ходьбу; стрибки вбік ігноруються. Нитка перебудовується, лише коли GPS ≥ 3 точки й ≥ 12 с показує місце далі 20–35 м від неї (або коли точність стала вдвічі кращою, ніж була при побудові). Старт нитки — точка доріжки в межах похибки, з якої найкоротше до дверей (`geoRoute`): без петель із паралельної доріжки. Тимчасова втрата сигналу не вимикає «від мене». Перевірка — `/tmp/walk.mjs` (імітація ходьби з шумом, стрибками і справжнім відхиленням).
- «Куди»: утримання номера чи пункту (0,48 с; на комп'ютері — права кнопка) — пункт втискається, над ним спливає «Поділитися · Відділення 16»; пункт при цьому не обирається. Посилання — `?to=<пункт>` (`shareTo`). Підказка про це — внизу віконця.
