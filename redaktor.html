Налаштування цього телефона
Як отримати ключ (для адміністратора)
  1. github.com → фото профілю → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Назва: «Редактор карти». Термін: 1 рік. Resource owner: ariadna-map.
  3. Repository access → Only select repositories → ariadna-map.github.io.
  4. Permissions → Repository permissions → Contents: Read and write. Більше нічого.
  5. Generate token, скопіювати й вставити сюди на телефоні сестри-господині. Якщо GitHub попросить схвалення організації ariadna-map — схваліть у її налаштуваннях.
  6. Телефон загубили — відкличте ключ там само (Revoke).

Оголошення для всіх відвідувачів

Відділення й місця

Геометрію карти (корпуси, двері, доріжки) редактор не змінює — для цього зверніться до адміністратора. Усі зміни записуються в журнал і їх можна повернути.
